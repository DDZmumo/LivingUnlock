# LivingUnlock 0.2.2 (2026-09-29)

## Highlights
- 合并并加固 [PR #1](https://github.com/DDZmumo/LivingUnlock/pull/1)：修复手机生物识别已经通过，但 Windows 登录组件因保险库权限过宽而读不到账户凭据的问题。
- Windows 控制台账户卡片新增“删除凭证”操作。

## Fixes
- WinUI 客户端只在当前用户的 LocalAppData 暂存凭据，再由管理员管理脚本发布到 ProgramData，并设置仅 SYSTEM 和 Administrators 可访问的权限。
- `promote-pair`、`promote-phone`、`promote-auth` 和 `promote-credentials` 会重新发布已有记录，使旧安装遗留的宽松权限得到收紧。
- 登录组件继续只接受受保护保险库中的凭据；用户目录中的暂存记录不会被 LogonUI 直接作为登录凭据使用。
- 安装包加入 `Repair-VaultAcl.ps1`。修复工具只处理系统保险库和符合 SID 命名规则的记录，并拒绝目录联接、符号链接及硬链接。

## Features
- 删除操作会先二次确认，然后清除当前账户在 Windows 本机保存的登录凭据、电脑端手机配对记录和 Authenticator 密钥。
- 删除成功后清空控制台中的账户显示；原生 PIN 和 Windows 账户密码不变。手机及验证器中的旧条目需要用户自行移除。

## Upgrade notes
- 需安装 Windows `LivingUnlock-Setup-0.2.2-x64.exe`；Android 安装包维持 0.2.1。
- 如果旧安装出现“手机指纹通过，但保存的账户凭据不见了”，安装 0.2.2 后可在管理员 PowerShell 运行：

  ```powershell
  & "$env:ProgramFiles\WindowsLockPin\tools\Repair-VaultAcl.ps1"
  ```

  该操作只修复保险库目录和记录权限，不删除凭据或配对。也可以在控制台重新保存凭据或重新绑定，让提权发布流程重新收紧权限。
- 删除后若要恢复 LivingUnlock 解锁，需重新保存账户密码并重新绑定所需方式。

## Verification
- 管理员隔离测试验证：正常记录权限修复；无关文件权限不变；目录联接、符号链接和硬链接被拒绝且外部目标权限不变；已有记录重新发布及本地暂存发布成功。
- WinUI Release 构建。
- Windows 安装器全新构建。
- 本版本尚未进行 Windows 安装器升级、ACL 修复工具及“删除凭证”的完整实机验收。

## Risk / notes
- Windows 安装器未使用 Authenticode 签名，仍为实验版本。
- 修复权限后应先确认原生 PIN 和账户密码可用，再验证 LivingUnlock 锁屏登录。
