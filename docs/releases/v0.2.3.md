# LivingUnlock Windows 0.2.3 (2026-09-30)

## Highlights

- 合并 [PR #2](https://github.com/DDZmumo/LivingUnlock/pull/2)：固定 WinUI 控制台为暗色主题，修复 Windows 应用模式设为浅色时部分文字变黑、难以阅读的问题。
- 自动识别当前登录的本地或 Microsoft 账户，填入本地用户名或关联邮箱。

## Fixes

- 自动检测先确认网络身份标志，再读取关联邮箱与 SID；本地账户不读取未定义的网络身份字段。
- API 失败、身份不受支持或邮箱信息不完整时，不会误报为本地账户。会优先保留已保存身份，并提示用户手动选择。
- 确认 Microsoft 账户时核对当前用户 SID，手动切换账户类型继续可用。

## Included fixes from 0.2.2

- 保留 [PR #1](https://github.com/DDZmumo/LivingUnlock/pull/1) 的保险库权限修复：客户端本地暂存、管理员发布并收紧系统记录权限。
- 安装包包含加固后的 `Repair-VaultAcl.ps1`，用于修复旧安装的保险库 ACL。
- 保留“删除凭证”按钮，二次确认后清除本机账户凭据、电脑端手机配对与 Authenticator 绑定。

## Upgrade notes

- Windows 11 x64：运行 `LivingUnlock-Setup-0.2.3-x64.exe`。如要求重启，请先保存工作。原生 PIN 和 Windows 账户密码入口继续保留。
- Android 继续使用 [0.2.1 正式签名 Compact](https://github.com/DDZmumo/LivingUnlock/releases/tag/v0.2.1)，本次未重新发布 Android 包。
- 若旧安装在手机指纹通过后仍提示找不到凭据，可安装新版后，在管理员 PowerShell 运行：

  ```powershell
  & "$env:ProgramFiles\WindowsLockPin\tools\Repair-VaultAcl.ps1"
  ```

  该工具修复权限，不删除账户凭据或绑定记录。
- 未能自动检测或填入邮箱时，可以手动选择账户类型并输入；密码仍由用户提供或从当前账户的已有绑定记录读取。

## Verification

- Windows 登录组件和配对工具重新编译；自包含 WinUI Release 客户端及 Inno Setup 安装包构建。
- 下载包可通过随附的 `SHA256SUMS-0.2.3.txt` 校验。
- 本次未进行浅色 Windows 模式、Microsoft 账户邮箱获取以及安装升级流程的实机验收。

## Risk / notes

- Windows 安装包尚无 Authenticode 签名，仍为实验版本。
- 使用前请确认原生 PIN 与账户密码可用，并在可恢复环境验证。
