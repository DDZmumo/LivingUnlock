LivingUnlock 0.2.3（实验版）

用途：在 Windows 11 x64 登录选项中增加 Authenticator 动态码与 Android 蓝牙生物识别入口，同时保留原生 Windows Hello PIN 和密码。
安装包包含 WinUI 3 控制台、配对工具、登录组件以及自包含的桌面运行时。

安装前必须确认：

1. 当前登录用户是管理员，并且知道本地账户或微软账户的密码（不是 PIN）。
2. 原生 PIN 可以正常解锁；手机丢失或程序异常时用 PIN 回退。
3. 这是未签名的实验软件。只使用可信来源提供的安装包，并核对随包 SHA-256。
4. 凭据提供程序会进入 Windows LogonUI。虽然已在一台 Windows 11 目标机验证，其他系统配置仍可能不兼容。
5. 微软账户密码会使用 Windows 机器范围 DPAPI 加密保存，文件仅允许 SYSTEM/Administrators 访问。具有本机管理员或 SYSTEM 权限的程序仍在信任边界内。

安装完成后会打开 LivingUnlock 控制台：

- 选择本地账户或微软账户，输入用户名或邮箱和账户密码；
- 绑定 Authenticator：扫描二维码或手动输入密钥，再输入 6 位码验证；
- 绑定手机：使用 LivingUnlock Android 扫描配对二维码，并开启蓝牙监听；
- 在锁屏“登录选项”中选择 LivingUnlock；
- 原生 PIN 和密码入口仍然可用。

日常解锁使用动态验证码，或在手机上确认解锁请求并验证指纹。

如果取消绑定窗口，登录组件虽已安装，但不会为未绑定用户显示验证码入口。原生 PIN 不受影响。

卸载：可从“设置 → 应用 → 已安装的应用”或开始菜单卸载。卸载器会询问是否同时清除加密绑定数据，默认选择保留。

恢复：优先切换 Windows 原生 PIN 或密码登录，然后通过系统“已安装的应用”卸载 LivingUnlock。
如登录界面异常，请进入 Windows 恢复环境的启动设置，以安全模式登录后卸载。升级要求重启时请先保存工作。

适用范围：Windows 11 x64、本地或个人微软账户、本机交互登录/解锁。不支持 RDP、UAC、域账户或强制双因素策略。
